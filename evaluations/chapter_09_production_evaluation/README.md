# Chapter 9: Production Evaluation

This chapter covers what happens after a model is deployed or close to deployment. The rewritten script keeps the ideas but removes the large framework-style structure.

## Topics

1. Regression testing
2. Canary testing
3. Shadow deployment
4. Drift detection
5. Monitoring
6. Alerting
7. CI/CD gates
8. Prompt versioning
9. Continuous benchmarking
