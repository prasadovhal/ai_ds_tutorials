# Chapter 1: Foundations of LLM Evaluation

This chapter introduces the basic ideas behind evaluation. The code is now written as one beginner-friendly file with small functions and a simple top-to-bottom flow.

## Topics

1. Why evaluation matters
2. Offline vs online evaluation
3. Intrinsic vs extrinsic evaluation
4. Human vs automatic evaluation
5. Reference vs reference-free evaluation
6. Model-based evaluation
7. Regression testing
8. Continuous evaluation
9. Evaluation lifecycle
10. Evaluation pipeline
11. Failure analysis and error taxonomy
12. Dashboard basics
13. CI/CD gates

## Files

- `main.py`: run this file
- `theory.md`: chapter notes and concepts
- `sample_data.json`: sample chapter data

## Run

```bash
cd chapter_01_foundations
python main.py
```

## What Changed

- no classes
- no chapter-local `dataset.py`, `evaluator.py`, or `hands_on.py`
- one file only for code
- smaller functions and simpler flow
