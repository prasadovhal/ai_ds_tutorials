# Project 7: Evaluation Dashboard

ASCII dashboard with comprehensive metrics and visualizations.

## Run
```bash
cd projects/07_eval_dashboard
python main.py
```

## What It Does
- Loads data and simulates model predictions
- Computes accuracy, F1, precision, recall per class
- Renders ASCII bar charts and confusion matrix
- Saves report to JSON file
- Prints latency percentiles and token usage

## Dependencies
Python standard library only
