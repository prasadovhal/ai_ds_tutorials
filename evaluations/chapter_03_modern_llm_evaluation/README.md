# Chapter 3: Modern LLM Evaluation

This chapter introduces modern evaluation dimensions used for LLM outputs. The code is now written to be easy to read line by line.

## Topics

1. Correctness
2. Relevance
3. Helpfulness
4. Completeness
5. Consistency
6. Hallucination
7. Faithfulness
8. Groundedness
9. Instruction following
10. Fluency
11. Coherence
12. Safety
13. Toxicity
14. Bias
15. Creativity
16. Readability
17. Reasoning quality

## Files

- `main.py`: run this file
- `theory.md`: concepts and chapter notes
- `sample_data.json`: sample chapter data

## Run

```bash
cd chapter_03_modern_llm_evaluation
python main.py
```

## Goal

The main goal is not perfect scoring logic. The goal is to help a beginner understand what each evaluation dimension means.
