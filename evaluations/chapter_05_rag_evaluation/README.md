# Chapter 5: RAG Evaluation

This chapter covers how to evaluate a Retrieval-Augmented Generation pipeline. The code is now simplified into one file with direct examples.

## Topics

1. Retrieval metrics
2. Generation metrics
3. End-to-end RAG scoring
4. Framework comparison

## Retrieval Metrics

- Context precision
- Context recall
- Context relevance
- Hit rate
- MRR
- NDCG

## Generation Metrics

- Answer relevance
- Faithfulness
- Groundedness
- Citation correctness
- Hallucination rate

## Files

- `main.py`: run this file
- `theory.md`: chapter notes
- `sample_data.json`: sample chapter data

## Run

```bash
cd chapter_05_rag_evaluation
python main.py
```
