This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a knowledge repository collecting curated best practices, tips, and techniques for efficient use of Claude Code. It is not a software project — it contains reference articles and compiled guides, not application code.

## Structure

- `articles.txt` — Source URLs (Medium articles) on Claude Code productivity
- `claude-code-best-practices.md` — Compiled, ranked summary of techniques and token optimization (49 items across 7 tiers)
- `skills.md` — Complete guide to agent skills: concept, creation, and Claude Code specifics with real-world examples

## Working Conventions

- Content files are Markdown. Maintain consistent heading hierarchy and formatting.
- When adding new content, preserve the ranked tier structure in `claude-code-best-practices.md` (Tier 1 = highest impact, Tier 7 = lowest).
- New article URLs go in `articles.txt`, one per line.
- Platform: Windows 11, shell is bash (Git Bash). Use forward slashes in paths.
